## 🚀 Run Locally

### Prerequisites

- Node.js 20+

### 1. Clone the Repository

```bash
git clone https://github.com/vipparthi-akshay/ai-for-marketers-hackathon-visionaryai.git
cd ai-for-marketers-hackathon-visionaryai/frontend
```

### 2. Install & Start

```bash
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.

## 🚢 Deployment

The repository includes a **GitHub Actions** workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the site to **GitHub Pages** on every push to `main` or `master`.
